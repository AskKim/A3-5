- **Three-Layer Boundaries:** `@engine/*` (`src/engine/` — zero livestock/pedigree terms, zero DOM outside `bridge/` & `storage/`), `@features/*` (`src/features/` — zero cross-feature sibling imports), `@domain/*` (`src/domain/` — pure TS, zero DOM), `@app/*` (`src/app/` — composition root). - **Token-Saving Edits (Required):** Change existing files with targeted diffs (`str_replace` / patch), never whole-file rewrites; report `git diff`, not full files; read only the needed line window; batch independent tool calls; keep scratch files in `/tmp`; never re-save account skills just to check read-back. Full rules: `AGENTS.md` §6.
- **Verify:** Run `npm run verify` (`lint`, `test`, `verify:improvements`, `verify:layers`, `verify:engine`, `verify:extraction`) and `npm run build` before finishing code changes; log significant changes in `src/domain/improvementRegistry.ts` and `IMPROVEMENTS.md`.
